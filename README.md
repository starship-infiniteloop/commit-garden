# 🌱 What is CommitGarden?

CommitGarden is an interactive productivity experience that visualizes your coding consistency as a growing virtual garden.

Instead of staring at boring streak counters and contribution grids, your GitHub activity directly affects:
- 🌿 garden growth
- 🌸 bloom evolution
- 🌳 tree progression
- 🌦️ environmental states
- ✨ ecosystem visuals

Every commit contributes to the life of your digital sanctuary.
